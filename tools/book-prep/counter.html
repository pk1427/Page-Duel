Counting rules
Illustrated humanscount.
Photographscount.
Statues/portraits/paintings inside the pagecount.
Face with no body1.
Partly visible personcount if head or face visible.
Tiny background figuresonly if individually distinguishable.
Crowd too dense to countcount the clearly visible ones and tick "ambiguous".
Humanoid characters (fairies, giants)count if drawn human-like.
Animalsdo not count.
Blank/text/decorative page0.
Same person twice on one pagecount each appearance.
Full-page illustration across both pagestick "excluded".
