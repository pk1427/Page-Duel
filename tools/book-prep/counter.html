Counting rules
  • Illustrated humans → count
  • Photographs → count
  • Statues/portraits/paintings → count
  • Face with no body → 1
  • Partly visible person → count if head or face visible
  • Tiny background figures → only if individually distinguishable
  • Crowd too dense → count clearly visible people and mark ambiguous
  • Humanoid characters → count if human-like
  • Animals → do not count
  • Blank/text/decorative page → 0
  • Same person twice on one page → count each appearance
  • Full-page illustration across both pages → mark excluded
